# UNDER downloads

Official installers for the free UNDER VST3 plugins (Windows).

Get them from the website: https://under-sounds.vercel.app — or from the [Releases](https://github.com/marcuzzartist/under-downloads/releases) of this repository. UNDER does not publish them anywhere else.

## Check your download

The website lists the size and SHA-256 fingerprint of every installer. In PowerShell:

```powershell
Get-FileHash .\Under_Pack_1.0.0_Windows_Setup.exe -Algorithm SHA256
```

If the fingerprint does not match, delete the file and download it again from the links above.
